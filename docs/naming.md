# Connact.ai Project Naming Convention

## Project Naming

The external product name should be uniformly **Connact.ai**, with fixed capitalization and decimal point. Document titles, Demo, API titles, and development prompts should use the same name. Delivery files and directories should use the `connact-ai-` prefix; four-phase prompts follow the numbering rule of `prompt-01-…` to `prompt-04-…`.

The repository directory `coldemail`, existing database/database user `meridian`, test database `meridian_test`, internal package name `meridian-workspace`, container user, and browser storage key are compatibility identifiers and should retain their original values, not displayed as product names. This product name does not require database migration or clearing user data.

Current delivery package: `outputs/connact-ai-design-package/`. Historical deliverables and `work/delivery/naming-before/` are records from before the change; subsequent deliveries will use the current package.
